# Arrow VPN 3.1.6 — Release notes

**Scope:** Windows desktop client, incremental source patch over 3.1.5. This ZIP is **not** a built installer; users must build/test in Windows before releasing it.

## What's new

- A **blue refresh** button now appears beside the version in the **Technical Support** panel. Hover to see **Check for updates** (localized to ES/EN/RU).
- When an update is detected, the button turns **green with a download icon**. The installed version appears struck through, followed by an arrow and the new version.
- If the user chooses **Later**, the panel continues to offer the download during the **same running app session**. A *complete quit and restart* repeats the automatic update notification when an update remains available. Minimizing to the system tray does not count as quitting.
- OTA metadata discovery requests all four `latest.yml` mirrors in parallel and prefers the latest release, not simply the first mirror to respond. Download continues to use electron-updater validation and same-version mirror fallback.
- The messenger brand **Session** is no longer mistranslated as a meeting (ES: `ID de Session`, EN: `Session ID`, RU: `ID Session`).
- **Windows tray tooltip** explicitly says **Arrow VPN**.

## Existing behavior retained

- Manual OTA download and explicit **Restart & install**; no automatic install on app quit.
- Background checks at launch and periodically thereafter.
- 3.1.5 smart routing / RU Direct, VPN/proxy controls, Kill Switch and existing subscriptions.
- Existing keys, UUIDs and Xray/REALITY endpoints are not modified by this patch.

## To build and validate

```powershell
npm ci
npm run check
npm test
npm run build
```

Use Node.js **24+** as required by `package.json`. Test update detection, Later, the green download control, install/restart, and tray tooltip on Windows before publishing. The automated tests do not exercise a real Windows install.

## Publishing OTA

Upload `ArrowVPN-Setup-3.1.6.exe`, its `.blockmap` and the **matching** `latest.yml` generated by Electron Builder to GitHub Releases (tag `v3.1.6`) and sync your mirrors. Merely compiling this patch will not update existing installations.

See [`CHANGELOG.md`](CHANGELOG.md) for the project history and [`SMART_ROUTING_README.md`](SMART_ROUTING_README.md) for the 3.1.5 routing feature that remains unchanged.
